全国の鉄道路線や公共交通機関を利用して遊ぶ、**2チーム対抗の大規模リアルタイム鬼ごっこ Web アプリケーション**です。  
プレイヤーはスマートフォンのブラウザからアプリのインストールやアカウント登録不要ですぐに参加でき、管理者は専用ダッシュボードからゲームの進行、ミッション配信、位置強制公開、スコア管理をリアルタイムに操作できます。

> **💡 Firebase Sparkプラン（完全無料版）対応:**
> クレジットカード登録が必要な有料プラン（Blaze）や Cloud Functions を一切排除し、**完全無料の「Firebase Sparkプラン」のみで本番運営できるサーバーレスアーキテクチャ**を採用しています。

## 🌟 主な特徴 & 注目機能

### 🚆 1. 【新機能】駅・駅間走行区間・進行方向の自動サジェストシステム
GPS 座標から「今どの路線のどの駅、あるいはどの駅間にいるのか」を瞬時に自動判定し、マップ上部に提案カードを表示します。

```text
[ 駅構内・ホームにいる時 ]
📍 駅を検出 (約30m)
東京 (東海道新幹線 / JR山手線 他)  [設定] [他の候補▼]

[ 電車で走行中の時 ]
🚆 走行中の区間を推定 (線路から約20m)
JR山手線 渋谷〜恵比寿間 (次は恵比寿)  [設定] [他の候補▼]
⚡ 現在地の自動反映 [ オート ON ]
```

- **📍 駅ホーム・構内検出（AT_STATION）**:
  - 駅の中心から 250m 以内にいる場合、乗り入れ路線を含む駅名（例: `東京 (JR山手線 / 東海道新幹線 他)`）を最優先でサジェスト。
- **🚆 駅間走行区間の推論（IN_TRANSIT）**:
  - 電車に乗って走行中の場合、全国 8,988 駅の接続ネットワークと直交幾何計算により、線路沿い（600m以内）の走行区間（例: `JR山手線 渋谷〜恵比寿間`）を自動推定。
- **🧭 進行方向 & 次駅の自動判定**:
  - 連続する測位ベクトルと線路の向きから、どちらの駅に向かっているかを判定し、「次は恵比寿」のように進行方向順の区間と次の停車駅を表示。
- **⚡ オートチェックイン（自動反映モード）**:
  - カード内の「⚡ 現在地の自動反映」を ON にすると、手動でボタンを押さなくても移動に合わせて現在地が自動的に更新されます。
  - GPS の一時的な測位ブレを防ぐ**2連続判定フィルター（デバウンス）**を備え、誤判定や通信の浪費を防止します。
- **📶 オフライン PWA 完全対応**:
  - 駅ネットワークデータは Service Worker により端末内にキャッシュ。地下鉄構内や電波の弱い山間部でも数ミリ秒以内で推論が動作します。

## 🎮 プレイヤー向け遊び方ガイド

### 1. ゲームへの参加（メールアドレス不要・高セキュリティ）
1. 主催者から共有された URL（`/#/`）にアクセス、または管理画面から提示された **QRコードをスマホのカメラで読み取り** ます。
2. 初回参加は「**新規エントリー**」タブで以下を入力するだけです:
   - **ユーザーID**: 半角英数字4文字以上（例: `yamada01`。メールアドレスの入力は一切不要でプライバシー安心）
   - **パスワード**: 6文字以上
   - **ニックネーム**: ゲーム中に表示される名前
   - **所属チーム**: **Team A** または **Team B** を選択
3. 「ゲームに参加する」をタップすると即座にマップ画面へ移動します。
4. **中断・再開ログイン**:
   - スマホの充電切れや誤ってブラウザを閉じた場合、別端末へ引き継ぎたい場合も「**再開ログイン**」タブからユーザーIDとパスワードを入れるだけで即座に復帰できます。

### 2. マップ画面の操作
- **自分の現在地**: 青いピン（あるいはチームカラー）で表示されます。
- **現在地の設定**:
  - 駅や電車に乗ると、画面上部に**提案カード**が出現します。
  - **「設定」**をタップすると、自分の現在地ステータス（`lastStation`）が更新され、他の仲間や鬼にも伝わります。
  - **「⚡ 現在地の自動反映」**をタップして「オート ON」にしておけば、移動中にスマホを操作しなくても自動で更新されます。
  - 「他の候補」をタップすると、乗り入れ路線の別駅や近隣駅一覧から手動で選ぶことも可能です。
- **画面の常時点灯（Wake Lock）**:
  - マップを開いている間はスマートフォンの画面が自動消灯しないため、移動中も快適に確認できます。

### 3. ゲームの基本ルール
| 役割 | 目的・できること |
| :--- | :--- |
| **鬼（ONI）** | 逃走者を追跡し、接近したら画面の**「捕獲」**ボタンをタップして確保する。<br>捕獲に成功すると攻守が交代し、チームに **+50pt** が入ります。 |
| **逃走者（RUNNER）** | 鬼から逃げつつ、各地のミッションをこなしてスコアを稼ぐ。<br>危険な時は**「無敵カード」**を使って 30 分間捕獲を無効化できます。 |

- **無敵カード**:
  - 逃走者チームが使える強力な防御アイテムです。
  - 使うと **30分間**、鬼からの捕獲を一切受け付けなくなります（タイマーが画面に表示されます）。
- **待機モード**:
  - 新幹線移動中や食事・休憩時など、一時的にゲームから安全に離脱できる機能です（60分間）。期限が切れると自動的にアクティブへ復帰します。
- **ミッション達成報告**:
  - 管理者から配信されるミッション（例:「○○駅の駅名看板を撮影せよ」「名物を購入せよ」等）を達成したら、ミッション画面から報告します。
  - 達成するとチームおよび個人にスコアが加算され、さらに **20% の確率で無敵カード**がボーナスとして手に入ります！
- **SOS（緊急通報） & リタイア**:
  - 体調不良、怪我、トラブルの際はいつでも「SOS」ボタンを押せます。
  - SOS を発信すると、現在地が管理者の専用緊急マップへ即座に送信され、運営スタッフが救護に向かえます。

## 🛡️ 管理者向け運営ガイド（専門知識不要・完全ノーコード）

管理者は専用画面から、プログラミングやデータベース操作を一切行わずに直感的なクリック操作だけでゲームを運営できます。

### 1. 管理画面へのアクセス & 初期セットアップ
- URL: `/#/admin`（エントリー画面下の「運営管理者の方はこちら」リンクからも移動可能）
- **初回管理者セットアップ（1分で完了）**:
  - 初めて利用する際は「初回管理者セットアップ」をクリック。
  - 希望の**管理者ID**と**パスワード**（8文字以上）を入力するだけで、初回限定のセキュアなワンタイム初期化（Atomic Bootstrap）により、Firebaseコンソールを触ることなく管理アカウントが即時発行されます（2人目以降の自己昇格は自動的に完全ロックされます）。
- **ワンクリック・初期セットアップウィザード**:
  - ログイン後、「🚀 初期セットアップウィザード（1クリック）」ボタンを押すだけで、セッション初期化と36件の標準ミッション登録が一瞬で自動完了します。

### 2. 参加者への案内（QRコード & コピー機能）
- 画面上に**参加用QRコード**が自動生成されます。
- プロジェクターで投影したり、紙に印刷して提示するだけで参加者がスムーズにエントリーできます。
- 「参加URLをコピー」「LINE用案内文をコピー」ボタンで、チャットグループへの周知も1タップです。

### 3. イベント期間に合わせた柔軟なフェーズ運用（1日・2日両対応）
イベントのスケジュールに合わせてボタン1つでフェーズを切り替えられます。
- **1日イベントの場合**:
  - `DAY 1 開始` → 昼休憩時などは `一時中断` / `再開` → 終盤に `クライマックス開始（最終ミッション）` → `ゲーム終了（結果発表）`
- **2日イベントの場合**:
  - 1日目の終わりに `1日目終了` → 2日目の朝に `DAY 2 開始` → `一時中断` / `再開` → `クライマックス開始` → `ゲーム終了（結果発表）`
- 任意のタイミングで**「🔄 攻守交代」**を実行して鬼と逃走者を入れ替えることも可能です。

### 4. ノーコード・ミッションセンター
管理画面内のミッションセンターで、ミッションの配信・作成・承認を直感的に操作できます:
- **配信中ミッションの管理**: 現在発動中のミッション一覧、対象チーム、残り時間をリアルタイムに確認。
- **ミッションカタログ（36件の標準ミッション＋オリジナル）**:
  - カードの **「全員へ」「Team A」「Team B」** ボタンをタップするだけで、指定したチームに即時配信。
  - 「🎲 ランダム配信」でサプライズイベントも演出可能。
  - **「＋ 新規ミッション作成」**: タイトル、説明、獲得ポイント（pt）、制限時間（分）、カテゴリ（写真・移動・謎解きなど）を自由に入力して独自ミッションを追加・編集・削除できます。
- **手動達成承認・ポイント付与**:
  - 参加者から写真を見せてもらったり報告を受けた際、プレイヤーとミッションを選んで「承認してスコア付与」を押せば、即座にポイント加算＆無敵カード抽選が実行されます。

### 5. 安全管理（緊急通報マップ）
- プレイヤーが SOS を発信した場合、専用の赤色アラートと緊急マップが表示され、正確な緯度経度を確認できます。

## 📱 スマートフォンでの推奨設定（PWA）

本アプリは **PWA（Progressive Web App）** に対応しています。ホーム画面に追加することで、アドレスバーのない全画面ネイティブアプリ感覚で遊ぶことができます。

- **iPhone / iPad (Safari)**:
  1. Safari でアプリの URL を開きます。
  2. 画面下部の中央にある **共有ボタン（四角から矢印が出ているアイコン）** をタップ。
  3. メニューから **「ホーム画面に追加」** を選択します。
- **Android (Chrome)**:
  1. Chrome でアプリの URL を開きます。
  2. 画面右上の **メニューボタン（縦の3点リーダー）** をタップ。
  3. **「ホーム画面に追加」** または **「アプリをインストール」** を選択します。

## 🏗️ システム構成と無料運用の仕組み

本アプリは **Firebase Spark プラン（完全無料）** の枠内で動作するように極限まで最適化されています。

```text
[ プレイヤー / 管理者端末 (PWA) ]
  │
  ├─ 全国駅・路線幾何推論エンジン (クライアント完全完結 / 8,988駅 / オフライン対応)
  │    ├─ 最寄り駅判定 (AT_STATION: 250m以内)
  │    ├─ 駅間線分直交判定 (IN_TRANSIT: 600m以内)
  │    └─ 進行方向ベクトル計算 (内積・コサイン類似度)
  │
  ├─ GPS通信量スロットリング (BaaSクォータ保護)
  │    └─ 30m移動 / 60秒経過 / 5分生存心拍のみ Firestore へ書き込み
  │
  └─ クライアントサイド トランザクション (runTransaction)
       ├─ 捕獲処理（攻守交代、30分待機、無敵カード付与、スコア+50pt）
       ├─ 無敵カード発動
       └─ ミッション達成記録

[ Cloud Firestore (無料枠: 1日5万回読み取り / 2万回書き込み) ]
  └─ 厳格なセキュリティルール (firestore.rules)
       ├─ 同一チーム同士の捕獲を物理遮断
       ├─ スコア改ざん・無敵カード不正付与の完全遮断
       └─ プレイヤープライベート座標の秘匿 (privateLocations/{uid})
```

## 🛠️ 開発者向けガイド

### 必要環境
- **Node.js**: `v22` 以上（LTS 推奨）
- **npm**: `v10` 以上

### ローカル起動
```bash
# 依存関係のインストール
npm ci

# 開発サーバー起動 (http://localhost:3000)
npm run dev

# 型チェック (TypeScript strict)
npm run typecheck

# 静的解析・Lint (Biome)
npm run lint

# 単体テストの実行 (221テスト全件)
npm test

# 本番ビルドの確認 (PWA Service Worker生成)
npm run build
```

### デプロイ手順（初回のみ）
1. [Firebase Console](https://console.firebase.google.com/) で無料プロジェクトを作成（Sparkプラン）。
2. Authentication で「匿名認証」と「メール/パスワード認証」を有効化。
3. Firestore Database を作成（東京リージョン `asia-northeast1` 推奨）。
4. `.env` に取得した Firebase API キー等を設定。
5. デプロイ実行:
   ```bash
   npx firebase login
   npx firebase use your-project-id
   npx firebase deploy
   ```
